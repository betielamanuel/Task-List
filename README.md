# Task Manager Application

## Overview

The Task Manager is a web application built using HTML, CSS, Bootstrap, React, and JavaScript. It allows users to manage tasks, including adding, updating, and deleting them. The application features a dynamic user interface with Bootstrap styling and supports dark mode for better user experience.

## Features

- **Task Management**: Add, update, and delete tasks.
- **Dynamic Task Display**: Tasks are rendered dynamically on the page.
- **Dark Mode**: Toggle between light and dark themes.
- **Form Validation**: Ensures all required fields are completed before submission.

## Technologies Used

- **HTML**: Structure of the web pages.
- **CSS**: Styling of the web pages, with a focus on responsiveness and layout.
- **Bootstrap**: For responsive design and component styling.
- **React**: Frontend library for building user interfaces (if applicable in future updates).
- **JavaScript**: For task management logic and form validation.

## Setup

1. **Clone the Repository**:
    ```bash
    git clone <repository-url>
    ```

2. **Navigate to the Project Directory**:
    ```bash
    cd task-manager
    ```

3. **Install Dependencies**:
    No additional dependencies need installation if using only HTML, CSS, and JavaScript. For React or other libraries, follow their respective installation instructions.

4. **Run the Application**:
    Open `index.html` in a web browser to view the application.

## File Structure

- **index.html**: Main HTML file with form and task list.
- **assets/css/style.css**: Custom CSS for styling the application.
- **assets/js/taskManager.js**: JavaScript for managing tasks and interactions.
- **assets/js/index.js**: JavaScript for initializing and handling form submission.
- **README.md**: This file.

## Usage

1. **Adding Tasks**: Fill out the form and submit it to add a task. Ensure all fields are completed.
2. **Marking Tasks as Done**: Click the "Mark As Done" button to update the task status.
3. **Deleting Tasks**: Click the "Delete Task" button to remove a task from the list.
